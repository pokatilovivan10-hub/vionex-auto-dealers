# Отчёт тестирования VIONEX LEADS v3.9.1

## Автоматические тесты

Команды:

```bash
npm test
npm run check
```

Результат:

```text
Project check passed
15 tests
15 pass
0 fail
```

Проверены публичные маршруты, CMS, форма заявок, авторизация, миграции, SEO-маршруты, статические ресурсы, отсутствие секретов в пакете и версия `/health`.

## Визуальная проверка первого экрана

Проверены:

- тёмная тема, ширина 1440 px;
- светлая тема, ширина 1440 px;
- мобильная версия, ширина 390 px.

Подтверждено:

- заголовок не сжат в узкую колонку;
- справа отображается крупная автомобильная сцена;
- у Hero нет отдельной внешней рамки;
- изображение не создаёт чёрный прямоугольный контейнер;
- отображаются четыре инфографические подписи;
- горизонтальное переполнение отсутствует;
- изображение загружается локально;
- нижние блоки страницы не изменены.

Точные измерения сохранены в `docs/BROWSER_AUDIT_V3.9.1.json`.

## Проверка обновления

Пакет установлен поверх изолированной копии v3.9.0.

Подтверждено:

- `/health` после обновления возвращает `version=3.9.1`, `ok=true`, `cms=true`;
- `.env` сохранён;
- каталог `data/` и контрольный пользовательский файл сохранены;
- проектная проверка и 15 тестов выполняются внутри установщика;
- ручной откат возвращает версию `3.9.0`;
- `.env` и `data/` сохраняются после отката.
