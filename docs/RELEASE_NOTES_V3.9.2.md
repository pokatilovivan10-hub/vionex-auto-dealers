# VIONEX LEADS v3.9.2

## Задача версии
Исправить только первый экран страницы `/services/auto-dealers` по утвержденному макету, не меняя нижние блоки страницы.

## Что изменено
- Убрано ощущение отдельной прямоугольной картинки справа: контейнер Hero не имеет рамки, фона, радиуса и тени.
- Автомобильная сцена встроена в общий фон Hero через общий фон секции, прозрачное изображение и плавное маскирование края.
- Подготовлены новые локальные изображения `auto-dealers-hero-v392.webp` и `auto-dealers-hero-v392-light.webp` с мягким alpha-fade по краям.
- Автомобиль показывается целиком через `object-fit: contain`, без жесткого crop.
- Левая текстовая колонка расширена; заголовок сохраняет две строки как в макете.
- Четыре инфографических бейджа перераспределены вокруг автомобиля без отдельного визуального контейнера.
- Светлая тема получила отдельную бесшовную версию изображения.
- Добавлена безопасная миграция CMS: стандартный путь изображения v3.9.1 заменяется на v3.9.2, пользовательское изображение не перезаписывается.

## Не изменялось
- Нижние блоки страницы.
- Формы и CRM delivery.
- Настройки CMS и администраторы.
- `.env`, заявки и загруженные пользователем медиа.
