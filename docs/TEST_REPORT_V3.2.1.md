# Отчёт тестирования VIONEX LEADS v3.2.1

## Цель выпуска

Устранить видимую прямоугольную границу динамической Canvas-планеты в светлой теме, не изменяя утверждённую композицию Hero, CMS и блок «Наши возможности».

## Автоматические тесты проекта

Команда:

```bash
npm run check
```

Проверяет:

- структуру проекта и обязательные файлы;
- версию приложения;
- синтаксис JavaScript/Node.js;
- 14 типов блоков конструктора;
- защищённую CMS и авторизацию;
- публичные маршруты, SEO, формы и локальное сохранение заявок;
- отсутствие секретов в коде;
- наличие светового feathering Canvas и ограниченного ambient-glow.
