# Отчёт тестирования VIONEX LEADS v3.2.0

## Объём изменения

Фактическая переработка блока «Наши возможности» по утверждённому референсу без изменения архитектуры CMS и серверной схемы.

## Статические проверки

- синтаксис серверных и клиентских JavaScript-модулей;
- наличие шести локальных SVG-иллюстраций;
- отсутствие секретов в публичных файлах;
- наличие 14 типов блоков конструктора;
- корректность версии в `package.json`, `VERSION` и `/health`.

## Серверные проверки

- публичные страницы и динамические маршруты;
- один H1 на каждой странице;
- canonical redirects;
- формы заявок и события;
- sitemap и 404;
- CMS-авторизация, CSRF, черновик, предпросмотр и публикация;
- медиатека и запрет опасного SVG;
- резервное копирование CMS;
- неразрушающая миграция до schema version 3.

## Браузерная проверка

Проверены:

- 1440×1100, тёмная тема;
- 1440×1100, светлая тема;
- 390×900, мобильная компоновка блока.

Результаты:

- горизонтального переполнения нет;
- шесть карточек присутствуют во всех режимах;
- все шесть SVG загружаются;
- сломанных изображений нет;
- повторяющихся ID нет;
- desktop-карточки имеют одинаковую ширину и высоту;
- на мобильном карточки перестраиваются в одну колонку.

Подробные размеры и пути ресурсов находятся в `docs/BROWSER_AUDIT_V3.2.0.json`.
