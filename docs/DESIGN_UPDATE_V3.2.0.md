# VIONEX LEADS v3.2.0 — блок «Наши возможности»

## Основание

Блок переработан по утверждённому визуальному референсу главной страницы. Изменения затрагивают фактическую HTML/CSS/SVG-верстку, а не изображение-макет.

## Что изменено

- сохранена компактная стеклянная панель с заголовком слева и пояснением справа;
- шесть карточек выровнены в одну строку на широком экране;
- прежние квадратные пиктограммы заменены шестью отдельными премиальными SVG-иллюстрациями;
- реализованы: мишень, поиск ЛПР, диалог, воронка, CRM-пазлы и растущая диаграмма;
- у иллюстраций прозрачный фон, градиентные грани, локальное свечение и мягкая тень;
- сохранены номера 01–06, стрелка перехода, кликабельность и hover/focus-состояния;
- темная и светлая темы имеют отдельные фоны, контраст и тени;
- при ширине до 1180 px карточки перестраиваются в 3 колонки;
- на телефоне карточки становятся вертикальным списком с иконкой слева;
- тексты, ссылки, порядок и тип иконки продолжают редактироваться через CMS.

## Безопасность и совместимость

- сторонние библиотеки и внешние CDN не добавлялись;
- SVG-файлы находятся в локальном каталоге `/public/assets/img/capabilities/`;
- исполняемый код в SVG отсутствует;
- структура CMS, администраторы, `.env`, заявки и медиатека не изменяются;
- миграция v3 только фиксирует `design_version=3.2.0` и не перезаписывает пользовательский контент.
