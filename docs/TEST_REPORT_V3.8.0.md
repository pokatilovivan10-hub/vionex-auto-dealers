# VIONEX LEADS v3.8.0 — отчёт тестирования

## Область проверки

- нишевая страница `/services/auto-dealers`;
- общая CMS и сохранение пользовательского контента;
- публичные динамические маршруты;
- форма заявки;
- темы, адаптивность и интерактивные компоненты;
- безопасное обновление с v3.7.0.

## Автоматические тесты

Команда:

```bash
npm test
```

Результат:

```text
15 tests
15 pass
0 fail
```

Проверены:

- `/health` и версия `3.8.0`;
- публичные CMS-страницы;
- нишевой маршрут автодилеров;
- миграции старых дизайн-версий;
- сохранение пользовательских текстов при миграции;
- canonical redirects;
- MIME-типы CSS, JS, SVG и изображений;
- sitemap;
- 404;
- валидная и невалидная заявка;
- first-party analytics без сохранения IP;
- авторизация CMS, черновик, предпросмотр, публикация и медиатека.

## Браузерная проверка

Проверенные сочетания:

- 1440×900, тёмная тема;
- 1440×900, светлая тема;
- 1024×768;
- 768×900;
- 390×844;
- 360×800, светлая тема.

Во всех сочетаниях:

- `scrollWidth === clientWidth`;
- один H1;
- нет дублирующихся ID;
- нет сломанных изображений;
- ошибок JavaScript не зафиксировано.

Количество элементов:

- 4 метрики;
- 3 тизера;
- 5 автомобильных кейсов;
- 6 карточек возможностей;
- 3 блока человеческого контроля;
- 3 тарифных плана;
- 5 AI-агентов;
- 6 FAQ.

## Интерактивность

Подтверждено:

- переключение тёмной/светлой темы;
- следующий слайд кейсов меняет активную карточку;
- переключение на квартальную оплату изменяет цену;
- FAQ меняет `aria-expanded` на `true`;
- нишевая форма открывается;
- заголовок формы соответствует автодилерской услуге;
- мобильное меню открывается;
- fallback видеокейса ведёт на рабочую страницу;
- присутствуют scan-слой и частицы Hero.

## Безопасность и данные

- секреты не добавлялись в код;
- `.env` не входит в заменяемые данные обновления;
- CMS-база и `data/uploads` сохраняются;
- форма сохраняет страницу и UTM-контекст;
- произвольный HTML/JavaScript через CMS не разрешён;
- боевые CRM-настройки не меняются.

## Ограничения проверки

- фактическая доставка в боевую CRM требует тестовой заявки после установки на сервер;
- PageSpeed Insights и реальный LCP проверяются на публичном URL после деплоя;
- реальный видеокейс не предоставлен, поэтому используется безопасный фасад со ссылкой на подробный сценарий.
