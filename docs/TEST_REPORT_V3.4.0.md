# Отчёт тестирования VIONEX LEADS v3.4.0

## Итог

Версия `3.4.0` прошла структурную, серверную, браузерную, миграционную и релизную проверку. Блокирующих ошибок не обнаружено.

Проверялась не только исходная папка проекта, но и фактически сформированные ZIP-архивы: чистая установка, обновление существующей CMS, ручной откат и автоматическое восстановление после искусственно вызванной ошибки health-check.

## Структурная самопроверка

Команда:

```bash
npm run check
```

Результат:

```text
Project check passed
13 tests
13 pass
0 fail
```

Проверены:

- версия приложения и обязательные файлы;
- 14 типов блоков конструктора;
- структура CMS и безопасные миграции;
- локальные изображения, CSS и JavaScript;
- отсутствие секретов в исходниках;
- принятый первый экран;
- блок «Наши возможности»;
- премиальная 3D-витрина кейсов.

Команда:

```bash
npm test
```

Результат:

```text

```

- `/health` и версия `3.4.0`;

- корректная раздача WebP-сцен и остальных локальных ассетов.

## Браузерная проверка

Проверены разрешения и темы:

- `1440 × 900` — тёмная и светлая темы;
- `1280 × 800` — фактическое автоматическое переключение;
- `1024 × 768` — тёмная тема;
- `768 × 900` — светлая тема;
- `390 × 844` — тёмная и светлая темы;
- `360 × 800` — тёмная тема.

На всех разрешениях подтверждено:

- 8 карточек и 8 точек навигации;
- одновременно активна ровно одна карточка;
- стартовая композиция: `AURA AUTO` слева, `MOTORAENA` по центру, `LEASEFORGE` справа;
- стартовый счётчик `2 / 8` соответствует центральному кейсу `MOTORAENA`;
- стрелки, точки, `Home`, `End`, свайп и автоматическое переключение работают;
- автопрокрутка перевела карусель с `2 / 8` на `3 / 8` после интервала;
- пауза при наведении и возобновление автопрокрутки работают;
- pointer-parallax изменяет CSS-переменные активной карточки;
- горизонтальное переполнение отсутствует;
- повторяющихся `id` и видимых сломанных изображений нет;
- ошибок JavaScript и браузерной консоли нет.

Отдельно проверены все восемь WebP-сцен: HTTP `200`, MIME `image/webp`, ненулевой размер файла.

Машинные результаты: `docs/BROWSER_AUDIT_V3.4.0.json`.

## Миграция и сохранность данных

Обновление проверено поверх чисто распакованной версии `3.2.1`, имитирующей действующий сервер.

Перед обновлением были добавлены контрольные данные:

- отдельная запись в CMS;
- отдельная метка в `cms_meta`;
- контрольная заявка в `data/leads.ndjson`;
- контрольное событие в `data/events.ndjson`;
- контрольный файл в `data/uploads/`;
- отдельный `.env`.

После установки `3.4.0` подтверждено:

- `/health` возвращает `version=3.4.0` и `cms=true`;
- `.env` не изменился;
- CMS-запись и метка сохранились;
- заявки, события и загрузки сохранились;
- миграция добавила недостающие сценарии `auto-new-cars`, `auto-used-cars` и `equipment-leasing`;
- версия схемы CMS повысилась до `5`;
- пользовательские материалы не были заменены.

## Ручной откат

Скрипт `ROLLBACK.sh` проверен на той же изолированной установке.

После отката подтверждено:

- приложение вернулось к версии `3.2.1`;
- CMS вернулась к исходной версии схемы `3`;
- добавленные миграцией сценарии отсутствуют;
- пользовательская CMS-запись сохранилась;
- `.env`, заявки и загруженный файл сохранились;
- сервер снова отвечает штатным `/health`.

## Автоматический откат при ошибке

Для проверки аварийного сценария health-check намеренно направлялся на неверный порт.

Установщик:

1. создал резервную копию;
2. установил файлы `3.4.0`;
3. успешно выполнил 13 тестов;
4. не получил корректный health-check;
5. автоматически восстановил файлы и CMS-базу `3.2.1`;
6. повторно запустил прежнюю версию.

Контрольные данные CMS и медиатеки после автоматического восстановления сохранились.

## Чистая установка из полного ZIP

Полный архив был распакован в новый пустой каталог.

Подтверждено:

- в архиве отсутствует `.env`;
- в `data/` отсутствуют runtime-база, заявки и секреты;
- `npm run check` проходит: `13/13`;
- приложение запускается на отдельном локальном порту;
- `/health` возвращает `version=3.4.0` и `cms=true`;
- `/` и `/admin` возвращают HTTP `200`;
- 3D-изображения кейсов возвращают HTTP `200`;
- в HTML присутствуют `AURA AUTO`, `MOTORAENA`, `LEASEFORGE` и разметка слайдера.

## Целостность архивов

Для обоих релизных ZIP выполнено:

```bash
unzip -tq <archive>
```

Ошибок целостности нет.

В архиве обновления дополнительно проверяется `MANIFEST_SHA256.txt`: установщик сверяет SHA-256 каждого файла до остановки приложения и замены боевых файлов.

## Ограничение достоверности контента

Встроенные автомобильные, лизинговый и остальные кейсы помечены как «Типовой сценарий». Они демонстрируют структуру и визуальную упаковку проекта, но не являются подтверждёнными результатами реальных клиентов. Перед коммерческой публикацией содержание необходимо заменить фактическими данными и разрешёнными материалами.
