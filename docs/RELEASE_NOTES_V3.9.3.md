# VIONEX LEADS v3.9.3

## Цель релиза

Перевести Hero страницы `/services/auto-dealers` с единого фонового изображения на многослойную сцену, максимально близкую к утвержденному дизайну, без видимой прямоугольной рамки вокруг автомобильного визуала.

## Изменения

- Автомобиль вынесен в отдельный локальный прозрачный WebP-слой `public/assets/img/auto-dealers-car-v393.webp`.
- Фон сцены теперь формируется отдельно средствами CSS и Canvas: свечение, data-grid, орбиты, узлы и движущиеся импульсы.
- Плавающие KPI-бейджи являются DOM-элементами, а не частью картинки.
- Через CMS для Hero редактируются:
  - изображение автомобиля;
  - X/Y автомобиля;
  - масштаб автомобиля;
  - высота визуальной сцены;
  - текст каждого плавающего бейджа;
  - встроенная иконка или загруженная графика;
  - X/Y бейджа;
  - ширина бейджа;
  - размер графики;
  - цветовой акцент;
  - включение/выключение динамической data-сцены;
  - включение/выключение плавной анимации.
- Сохранены dark/light темы и адаптивная перестройка.
- Добавлена миграция schema v14, которая обновляет только штатный Hero и не заменяет пользовательское изображение из CMS.

## Безопасность обновления

`.env`, `data/cms.sqlite`, `data/uploads`, заявки и пользовательские настройки не входят в принудительную замену состояния и сохраняются установщиком.
