# VIONEX LEADS v3.10.0

Точечная переработка первого экрана `/services/auto-dealers` по утвержденному визуальному референсу.

- расширена текстовая колонка и выровнена геометрия Hero;
- автомобиль вынесен в отдельный прозрачный WebP-слой без рамки и прямоугольной подложки;
- фон сцены строится отдельными CSS/Canvas слоями;
- орбиты, сетка, узлы и световые импульсы отдельны от автомобиля;
- плавающие HUD-карточки являются редактируемыми HTML-элементами;
- для HUD доступны X/Y, ширина, размер иконки, акцент, собственное изображение и тип `standard/chart`;
- добавлены мини-графики для карточек типа `chart`;
- сохранены dark/light и адаптивные режимы;
- добавлена безопасная CMS-миграция 3.9.3 → 3.10.0, не перезаписывающая пользовательское медиа.

Проверка: `npm run check` — 16/16 tests passed.
